💡 本页面演示了 绝对路径 与 相对路径 引用图片的两种方式。

① 绝对路径引用的图片

写法：<img src="http://xxxx.com/1.png">

这里的 http://xxxx.com/1.png 是一个完整的 URL，浏览器会直接去这个地址拿图片。

⚠️ 实验时你可以把上面 src 换成老师给的 http://xxxx.com/1.png， 前提是 xxxx.com/1.png 必须是一个真实可访问的图片地址。
如果只是做演示，用一个真实存在的网络图片 URL 即可。

② 相对路径引用的图片

写法：<img src="../image/1.png">

相对路径是相对于当前 HTML 文件自身位置去找图片文件。

为了让 ../image/1.png 成立，我们把页面放到子目录 /pages/ 下：

✅ image/1.png = 从当前文件（index.html 在根目录）同级的 image/ 文件夹里找 1.png
如果你把 HTML 放 pages/ 子目录里，就要写 ../image/1.png（上一级→找image→找1.png）

路径概念小结

  • 绝对路径：以 http:// 或 https:// 开头，是完整的 URL，不依赖本地文件结构
  • 相对路径：不以 http:// 开头，以 ./ 或 ../ 或文件夹名开头， 是"站在当前文件位置"去找邻近文件，文件必须存在于仓库中并被 git push 上去
  • ./ = 当前目录（可省略不写）
  • ../ = 上一级目录
